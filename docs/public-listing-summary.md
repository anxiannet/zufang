# Public Listing Summary Field

## Purpose

`listing_ai_analysis.public_summary` is the only summary field intended for public frontend display.

It is used by the NTU rental homepage to show a clean, readable listing introduction without exposing raw source content.

## Field Positioning

This field is not a data summary.

This field is not a structured field mirror.

This field is a rewritten description of the living experience.

The goal is to help users quickly understand:

- 房屋亮点
- 居住体验
- 周边环境
- 通勤特点
- 适合什么类型的租客

without repeating information already displayed elsewhere.

---

## Difference Between Fields

### listing_indexes.summary

Purpose:

Search indexing.

May contain:

- original ad text
- contact information
- repeated content
- source wording
- noisy data

Must NOT be displayed directly.

### listing_ai_analysis.summary_ai

Purpose:

Internal AI analysis.

May contain:

- tags
- classification results
- model notes
- recommendation signals

Not intended for frontend display.

### listing_ai_analysis.public_summary

Purpose:

Public-facing description.

Must be:

- readable
- natural
- rewritten
- neutral
- human-friendly

---

## Hard Rules

Do NOT repeat information already shown in structured fields.

Do NOT include:

- rent
- postal code
- room type
- move-in date
- phone number
- WeChat ID
- WhatsApp number
- Telegram handle
- landlord name
- exact unit number
- block number

The page already shows those values separately.

Repeating them makes the reading experience worse.

---

## What To Write Instead

Focus on:

### Living Experience

Examples:

- 房间采光充足
- 家具配置完整
- 学习空间较大
- 收纳空间充足
- 居住环境安静
- 人数较少

### Surrounding Environment

Examples:

- 周边生活配套完善
- 日常采购方便
- 餐饮选择较多
- 社区成熟

### Transportation

Examples:

- 通勤较为方便
- 巴士线路丰富
- 前往校园相对便捷

### Tenant Profile

Examples:

- 适合重视安静环境的租客
- 适合长期居住
- 适合以学习为主的学生

---

## Good Example

房间采光充足，家具配置完整，拥有较大的学习和收纳空间。整套居住人数较少，环境相对安静，适合希望兼顾学习与生活品质的租客。

---

## Another Good Example

周边生活配套成熟，日常采购和用餐便利，公共交通选择较多。居住规则相对宽松，适合希望长期稳定居住的租客。

---

## Bad Example

位于Jurong West区域的普通房，月租约$1200，邮编648364，可做饭，可报地址。

Reason:

This only repeats structured fields.

It adds almost no value.

---

## Generation Strategy

The AI should:

1. Read the original listing.
2. Extract the meaning.
3. Rewrite it naturally.
4. Remove all contact information.
5. Remove all exact addresses.
6. Remove duplicated structured data.
7. Generate 80-180 Chinese characters.

The output should feel like a short editorial description, not a field summary.

---

## Frontend Usage

Homepage listing cards should query:

listing_ai_analysis.public_summary

If empty, fallback text should also follow these rules.

---

## Responsibility

This field should be generated by the AI enrichment pipeline.

The frontend should only read and render it.
