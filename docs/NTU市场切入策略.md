# NTU市场切入策略

## 为什么从NTU开始

因为这是一个天然垂直市场。

特点：

- 用户集中
- 房源集中
- 需求稳定
- 每年持续产生新租客

---

# 第一阶段目标

建立 NTU 周边真实房源数据库。

重点区域：

- Pioneer
- Boon Lay
- Jurong West
- Jurong East
- Lakeside

---

# 第一批用户

优先获取：

100位真实屋主。

而不是1000个租客。

原因：

房源是供给。

供给决定平台价值。

---

# 第一批房源

目标：

300套真实房源。

每套至少包含：

- 图片
- 租金
- 邮编
- 房型
- 联系方式

---

# 获取方式

4. Facebook
5. 屋主转介绍
