## 3. 简短询问版

适合屋主不想填长表时使用：

> 为了帮您整理房源，方便补充一下：房型、租金、邮编、入住时间、是否包水电、是否可报地址、是否可双人、是否可煮，再发几张房间照片就可以。

## 4. 照片要求

建议屋主提供：

- 房间全景
- 床和书桌
- 衣柜或收纳
- 窗户采光
- 卫生间
- 厨房
- 公寓或组屋外观
- 楼下交通 / 周边设施

照片说明：

- 尽量横拍或竖拍保持清晰
- 不需要修图
- 避免拍到个人证件、姓名、门牌等敏感信息
- 如拍到敏感信息，可以先打码

## 5. 授权确认

收录前建议确认：

> 请问您是否同意维界将该房源的基础信息和照片整理后用于平台展示和推广？敏感信息不会公开，后续您也可以要求修改或下架。

屋主回复“可以”“同意”“没问题”后，再进入网站收录流程。
