# MVP开发路线图

## 核心原则

先验证需求。

不要先做复杂系统。

先获得：

- 100位真实屋主
- 300套真实房源
- 10个成功出租案例

---

# Phase 1

目标：上线可用版本

时间：1~2周

功能：

- 房源列表
- 房源详情
- 搜索
- 标签
- 图片展示
- 联系屋主

不做：

- 支付
- 聊天
- 复杂权限

---

# Phase 2

目标：建立数据优势

时间：2~4周

功能：

- 通勤分析
- AI标签
- AI简介
- 收藏系统
- 浏览统计

---

# Phase 3

目标：开始收费

时间：第2个月

功能：

- 房源置顶
- 房源海报
- 图片优化服务

---

# Phase 4

目标：建立壁垒

时间：第3个月以后

功能：

- 屋主认证
- 房源认证
- 租客画像
- 推荐系统

---
