# 竞争分析

## 真正的竞争对手是谁

维界最大的竞争对手不是其他租房网站。

而是：

1. 房产中介
2. 共享公寓公司
3. 微信群
4. 屋主自己的惯性

---

# 房产中介

优势：

- 专业销售
- 专业摄影
- 专业海报
- 大量租客资源

缺点：

- 成本高
- 主要服务高价值房源
- 普通房市场投入有限

维界优势：

- 成本更低
- 服务普通屋主
- 服务长尾房源

---

# 共享公寓公司

代表：

- Cove
- Hmlet
- Coliwoo

优势：

- 品牌强
- 流量大
- 专业运营

缺点：

- 只服务自己的房源

维界未来甚至可能成为他们的推广工具。

---

# 微信群

微信群是目前最大的竞争对手。

因为完全免费。

问题：

- 信息沉底快
- 无法搜索
- 无法积累数据
- 无法精准推荐

维界的价值是让信息沉淀。

---

# 屋主惯性

很多屋主会说：

我自己发群就好了。

事实上这是最大的竞争对手。

维界必须证明：

使用维界比自己发群更省时间。
