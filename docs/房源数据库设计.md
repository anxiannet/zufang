# 房源数据库设计

## 设计原则

维界最重要的资产不是网站。

而是房源数据库。

数据库设计必须支持：

- 房源展示
- AI推荐
- 通勤分析
- 租客匹配
- 数据统计
- 后续商业化

---

# 核心数据表

## landlords（屋主表）

字段：

- id
- name
- wechat
- whatsapp
- phone
- landlord_type
- verification_status
- created_at

认证状态：

- pending
- basic_verified
- verified

---

## listings（房源表）

核心字段：

- id
- landlord_id
- title
- description
- property_type
- room_type
- monthly_rent
- postal_code
- address
- latitude
- longitude
- available_date
- min_lease_months
- status

状态：

- draft
- active
- rented
- hidden
