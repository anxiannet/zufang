# 维界商业模式

## 核心定位

维界不是房地产中介。

维界是：

> 新加坡房源展示与推广平台。

核心能力：

- 房源整理
- 房源标准化
- 房源标签化
- 照片优化
- 海报制作
- 通勤分析
- 租客匹配
- 房源推广

我们帮助屋主提升房源展示能力。

---

# 为什么不是中介

传统中介的收入来自：

- 成交佣金
- 租约谈判
- 看房安排
- 合同签署

维界不参与：

- 谈判租金
- 代收租金
- 代收押金
- 签署租约

维界收入来自服务费。

本质更接近：

> 房源运营服务。
