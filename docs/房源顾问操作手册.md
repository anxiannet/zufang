# 维界房源顾问操作手册（V1）

欢迎加入维界房源顾问计划。

你的工作不是销售。

你的工作是：

帮助屋主更好地展示房源。

维界负责：

- 房源整理
- 照片美化
- 海报制作
- 网站收录

你负责：

- 联系屋主
- 建立信任
- 收集房源信息
- 推荐服务

## 第一步：寻找屋主

渠道：微信群、Facebook、Telegram、小红书、租房网站。

重点寻找：房东直租、无中介、屋主出租、个人出租。

避免：房产中介、经纪公司、代理。

## 第二步：添加微信

好友申请：

您好，看到您发布的房源。我是维界租房平台的房源顾问。目前正在帮助新加坡屋主免费整理房源信息和提升房源展示效果，想了解一下您的房源是否还在出租。

## 第三步：收集房源信息

收集：

- 房间照片
- 租金
- 房型
- 入住时间
- 是否可双人入住
- 是否可报地址
- 是否包水电
- 地点或邮编
- 联系方式
- 房源介绍

## 第四步：提交试用

免费试用包含：

- 房源信息整理
- 网站免费收录
- 免费美化1张房间照片

## 常见问题

Q：你们是中介吗？

A：不是。我们是房源展示与推广服务平台。

Q：收费吗？

A：试用免费，后续可升级照片美化（19.90 SGD）和房源海报制作（29.90 SGD）。

每天添加20-50位屋主，获取3-5套房源资料，完成1-2套试用案例。
