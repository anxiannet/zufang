# 维界房源顾问操作手册（V1）

本手册用于培训兼职房源顾问。目标是让新人即使不熟悉新加坡租房市场，也能按照标准流程联系屋主、收集房源、提交试用案例，并在合适时推荐付费服务。

## 1. 角色定位

你的身份：维界房源顾问 / 屋主联络员。

你不是房产中介，不做成交撮合，不收成交佣金，不替双方谈判租金。

你的工作是帮助屋主更好地展示房源：

- 整理房源信息
- 收集房源照片
- 协助网站收录
- 推荐照片美化与海报制作服务
- 邀请屋主加入交流渠道

维界负责：

- 房源结构化整理
- 照片美化
- 海报制作
- 网站收录
- 推广文案
- 兼职培训与答疑

## 2. 工作流程

### 第一步：寻找屋主

主要渠道：

- 微信租房群
- Facebook 租房群
- Telegram 租房群
- 小红书租房笔记
- 租房网站

优先寻找以下关键词：

- 房东直租
- 屋主直租
- 无中介费
- 个人出租
- 主人房出租
- 普通房出租
- 整套出租

避免优先联系：

- 明确写明中介 / agent / property agent 的账号
- 大量重复发布不同房源的账号
- 信息明显虚假或价格异常低的房源

### 第二步：添加屋主微信

好友申请模板：

> 您好，看到您发布的房源。我是维界租房平台的房源顾问，目前在帮助新加坡屋主免费整理房源信息和提升房源展示效果，想了解一下您的房源是否还在出租。

### 第三步：通过好友后开场

开场模板：

> 您好，感谢通过。请问您的房源目前还在出租吗？

如果屋主回复“还在”：

> 我们最近在做房源推广试用计划，可以免费帮您整理房源信息、收录网站，并美化1张房间照片。您可以先体验效果，满意后再决定是否需要升级服务。

### 第四步：收集资料

向屋主索取：

- 房间照片
- 房型：普通房 / 主人房 / 床位 / 整套
- 租金
- 入住时间
- 地点或邮编
- 是否包水电
- 是否可报地址
- 是否可双人入住
- 是否可煮
- 最短租期
- 联系方式
- 屋主补充说明

### 第五步：提交给维界

统一提交格式：

```text
屋主微信：
房型：
租金：
地点：
邮编：
入住时间：
是否包水电：
是否可报地址：
是否可双人：
是否可煮：
照片数量：
屋主备注：
是否申请试用：是
```

### 第六步：试用完成后跟进

试用完成后发送：

> 您好，您的房源资料已经整理完成，照片也已经完成优化。您可以先看效果。如果满意，后续可以升级照片美化或房源海报制作，让房源展示更专业。

升级服务：

- 照片美化：SGD 19.90，最多10张照片优化
- 房源海报制作：SGD 29.90，包含照片优化、专业海报、微信发布文案

## 3. 每日工作目标

建议目标：

- 每天添加屋主 20-50 位
- 每天获得有效回复 5-10 位
- 每天收集房源资料 3-5 套
- 每天完成试用提交 1-2 套

## 4. 工作原则

- 不硬推销
- 不夸大效果
- 不承诺一定出租
- 不冒充中介
- 不代收租金
- 不替屋主和租客谈判
- 先帮助屋主，再推荐服务

## 5. 核心话术

一句话说明维界：

> 维界是一个面向新加坡租房市场的房源展示与推广平台，主要帮助屋主整理房源信息、优化照片、制作海报和增加曝光。

一句话说明试用：

> 目前可以免费体验房源信息整理、网站收录和1张房间照片美化。

一句话说明收费：

> 基础试用免费，后续如果需要更多照片美化或专业海报，可以选择升级服务。

## 6. 注意事项

如遇到以下情况，先暂停并反馈给负责人：

- 屋主要求代收押金或租金
- 房源价格明显低于市场价
- 屋主拒绝提供基本地址或邮编
- 房源照片疑似盗图
- 对方要求你承诺出租结果
- 对方要求你以中介身份操作

记住：我们的价值是提升房源展示质量，不是做中介成交。
