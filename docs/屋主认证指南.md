# 屋主认证指南

本指南用于帮助兼职房源顾问初步判断对方是否更可能是真实屋主或真实出租人。认证的目标不是做法律鉴定，而是降低虚假房源、二房东冒充屋主、诈骗和中介误触的风险。

## 1. 基本原则

联系屋主时保持礼貌，不要一上来质疑对方。

推荐表达：

> 为了保障租客和屋主双方权益，我们平台会做基础信息核对。不是怀疑您，只是为了让房源展示更可信。

不要说：

> 你怎么证明你是真的屋主？

## 2. 初步判断信号

较可信信号：

- 对方能提供清晰房间照片
- 对方能说出具体邮编、楼层、房型
- 对方能说明入住时间、水电、租期等细节
- 对方愿意补充房源信息
- 对方愿意授权平台展示基础房源信息

需谨慎信号：

- 只发低价房源，不愿说具体地点
- 要求先付款才能看房
- 照片像酒店图、样板间或网图
- 同一个账号发布大量不同区域房源
- 自称屋主但表达像中介批量营销
- 不愿提供任何可核对信息

## 3. 建议核对的信息

基础信息：

- 房源邮编
- 房型：HDB / Condo / Landed / 其他
- 出租类型：普通房 / 主人房 / 床位 / 整套
- 是否屋主同住
- 是否可报地址
- 最短租期
- 水电网费用说明

补充信息：

- 可入住时间
- 是否可煮
- 是否可双人
- 是否有空调
- 是否有家具
- 是否有其他租客限制

## 4. 可请求的辅助证明

可以礼貌请求：

- 房间现拍照片
- 门牌或楼下环境照片，注意可打码
- Singpass / IRAS / 物业资料截图，敏感信息需打码
- 私人物业可提供物业账单、管理费账单或其他可证明关系的资料，敏感信息需打码

注意：不要要求屋主公开身份证、NRIC、完整产权文件或未打码的私人资料。

## 5. 认证话术

### 话术一：基础核对

> 为了让租客更放心，我们收录房源前会做基础核对。方便请您补充一下邮编、房型、入住时间、是否可报地址和是否包水电吗？

### 话术二：照片核对

> 如果方便的话，可以发一张房间现拍照片吗？不用拍到个人信息，主要是确认房源真实存在，也方便我们帮您整理展示。

### 话术三：敏感信息处理

> 涉及门牌、姓名、证件号等敏感信息都可以打码，我们只需要确认房源真实性，不会公开您的私人资料。

### 话术四：授权展示

> 您确认后，我们只展示房源基础信息、照片和联系方式/咨询方式。敏感信息不会公开。

## 6. 红线

兼职人员不得：

- 索取屋主完整身份证件
- 保存未打码敏感文件
- 对租客承诺“已完全认证”
- 代收押金、定金或租金
- 冒充持牌房产中介
- 代表屋主签约或谈判

## 7. 认证结果标记

建议内部使用以下标记：

- 待核对：资料不完整
- 初步可信：资料完整，照片清晰
- 已授权展示：屋主明确同意平台展示
- 风险房源：价格异常、资料矛盾或疑似中介/骗子

对外展示时用谨慎措辞，例如：

> 房源资料已由屋主提供，平台已做基础信息整理。看房和签约前请自行核实。
