# 房源推广服务介绍

本文件用于兼职顾问向屋主介绍维界服务。注意：不要承诺成交，不要说自己是中介。

## 1. 服务定位

维界提供的是房源展示与推广服务。

我们帮助屋主：

- 整理房源信息
- 优化房间照片
- 制作房源海报
- 收录到网站
- 生成发布文案
- 提升房源展示质量

一句话介绍：

> 维界帮助屋主把房源展示得更清楚、更专业，让租客更容易看到房源亮点。

试用版包含：

- 房源信息整理

适合：

- 普通房
- 主人房
- 公寓房间
- 整套出租
- NTU及周边区域房源

推荐话术：

> 您可以先免费体验一次，我们帮您整理资料、美化1张照片，并收录到网站。满意后再决定是否升级服务。

## 3. 照片美化

价格：SGD 19.90

包含：

- 最多10张照片优化
- 调亮

- 裁切

不包含：

> 很多房源不是房间不好，而是照片太暗、角度太乱。照片优化后，租客更容易看清房间条件。

## 6. 标准服务流程

1. 屋主提供房源信息和照片
2. 顾问整理资料并提交
3. 维界完成试用或付费服务
4. 屋主确认效果
5. 如满意，推荐升级服务
6. 服务交付完成后记录订单

## 7. 不应承诺的内容

不要承诺：

- 一定出租

- 保证有租客看房
- 保证小红书爆量
- 保证租金提高

可以表达：

- 提升展示效果
- 增加曝光机会
- 让租客更容易理解房源
- 帮屋主节省发布整理时间
