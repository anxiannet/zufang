# 兼职人员培训手册

本手册用于新兼职人员入门培训。请先阅读本文件，再阅读其他专项文档。

## 1. 你要做什么

你要做的是房源顾问工作：

- 找到正在出租房源的屋主
- 礼貌联系屋主
- 邀请屋主了解免费试用
- 收集房源信息和照片
- 提交给维界处理
- 在合适时推荐付费升级服务

核心目标：

> 帮助屋主把房源展示得更清楚、更专业。

## 2. 你不用做什么

你不用：

- 懂新加坡所有地名
- 懂复杂房产法规
- 自己制作海报
- 自己修图
- 自己建网站
- 直接成交租约

你不能：

- 冒充房产中介
- 代收押金或租金
- 承诺一定出租
- 替屋主和租客谈价格
- 使用虚假身份联系屋主

## 3. 每天工作步骤

### 第一步：找房源

在微信群、Facebook、Telegram、小红书等渠道寻找屋主直租信息。

关键词：

- 房东直租
- 屋主直租
- 无中介
- 普通房出租
- 主人房出租
- 整套出租

### 第二步：加微信

使用标准好友申请，不要写太长。

### 第三步：确认是否还在出租

通过好友后先问：

> 请问您的房源目前还在出租吗？

### 第四步：介绍免费试用

如果还在出租，介绍：

- 房源信息整理
- 网站免费收录
- 免费美化1张房间照片

### 第五步：收集资料

按照《房源信息收集表》收集资料。

### 第六步：提交内部整理

把资料按标准格式提交给负责人。

### 第七步：跟进升级

试用完成后，根据屋主反馈推荐：

- 照片美化：SGD 19.90
- 房源海报制作：SGD 29.90

## 4. 标准工作量

建议每天：

- 添加屋主 20-50 位
- 获得有效回复 5-10 位
- 收集房源资料 3-5 套
- 完成试用提交 1-2 套

前期重点不是马上成交，而是积累真实屋主和真实房源。

## 5. 沟通风格

推荐风格：

- 礼貌
- 简短
- 真诚
- 不压迫
- 不夸张

不要连续追问。

如果屋主没有回复，可以隔天轻轻跟进一次：

> 您好，打扰一下。昨天和您说的房源免费整理试用，如果您还需要出租，可以把房源资料发我，我帮您先整理一版。

仍不回复就停止。

## 6. 试用转化逻辑

不要一开始就卖服务。

正确路径：

```text
免费试用
→ 屋主看到效果
→ 建立信任
→ 推荐照片美化或海报制作
→ 完成付费服务
```

## 7. 常见错误

错误一：一上来就推销收费。

正确做法：先介绍免费试用。

错误二：承诺一定出租。

正确做法：说提升展示效果和曝光机会。

错误三：问太多敏感信息。

正确做法：只收集展示所需资料，敏感信息可打码。

错误四：把中介也当屋主联系。

正确做法：优先联系“屋主直租、无中介、个人出租”。
